# ETL dependencies.

# Pinned exactly, on purpose. "python etl/run.py --refresh reproduces /data
# from scratch" is an acceptance criterion, and /data is committed output that
# gets reviewed in diffs. A silent pandas or geopandas major bump could shift
# the numbers or the geometry and land in a pull request looking like an
# upstream data change. Pinning keeps the pipeline the only thing that varies.
#
# The monthly refresh will not pick up new versions on its own; bump these
# deliberately, re-run the ETL, and check the diff.
#
# Versions verified working on 2026-08-10 (Windows 11 + Ubuntu runner).
